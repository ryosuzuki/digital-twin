# Assets

This public repository does not include personal room scans, recordings, human models, screenshots, or private logs. Original absolute paths have been replaced with `/path/to/local-assets`. Configure each server/viewer with your own meshes, Gaussian representations, human models, or captures.

For `implementations/spatial-object-memory`, run `npm ci && npm run fixture && npm start` to generate and launch a purely synthetic fixture. This fixture does not represent an actual room or person. Other imported implementations require assets that are not supplied: cloning this repository alone does not recreate the original personal demos. Existing public video links remain in the original READMEs. Exact restoration details for private assets are retained only in private working records, not public Git.
